# AI Usage Report

## Tools Used

- ChatGPT
- Codex in Cursor

## How AI Was Used

AI was used mainly as a learning, planning, and review assistant.

It helped with:

- understanding the challenge requirements
- reviewing the iRail response structure
- discussing architecture and edge cases
- generating limited project boilerplate
- suggesting automated test cases
- reviewing accessibility and frontend styling
- checking task compliance and documentation

## My Contribution and Ownership

I made the final architecture and implementation decisions.

I integrated the frontend, backend, and iRail API, reviewed and modified generated code, verified the time-window and normalization logic, tested the application, and corrected suggestions that conflicted with the challenge.

Examples of rejected or changed suggestions include:

- adding a second public station endpoint
- caching the final filtered response
- automatically starting the full search while typing
- copying another railway brand’s design

All final code was reviewed, tested, and understood before submission.
